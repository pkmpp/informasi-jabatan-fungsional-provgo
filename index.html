1. Tambah & Perubahan Data JF

Tambahkan pejabat fungsional baru, mutasi antar-OPD, atau penyesuaian kuota Kebutuhan Formasi (ABK).

2. Sinkron Permanen ke GitHub

Simpan perubahan langsung ke data_jf.json di repositori GitHub agar data yang dihapus/diubah permanen di semua browser & laptop.

3. Upload & Ekspor Data

Unggah pembaruan data format Excel (.xlsx), CSV, atau JSON cadangan, serta ekspor seluruh data ke Excel atau data_jf.json.

4. Cetak & Reset Data

Cetak laporan resmi berformat kop Pemerintah Provinsi Gorontalo atau sinkronkan ulang data dari server/lampiran awal.

Sinkronisasi Permanen ke Repositori GitHub

Cara Kerja Sinkronisasi GitHub Pages:

Agar data yang dihapus, ditambah, atau diubah hilang secara permanen di semua browser dan laptop orang lain, aplikasi perlu memperbarui berkas data_jf.json di repositori GitHub Anda. Token hanya disimpan di browser Admin ini (tidak pernah dipublikasikan).

Buat di GitHub → Settings → Developer settings → Personal access tokens (Fine-grained: izin Contents: Read and write pada repo ini).

Alternatif Tanpa Token GitHub:

Unduh berkas terbaru lalu unggah manual melalui menu Add file → Upload files di GitHub:
